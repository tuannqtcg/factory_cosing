## Tri thức nghiệp vụ mới user cấp trong phiên (ngoài Excel — đã ghi ADR)
- **ADR-020**: 3 ca liên tục là chuẩn; 3 nhóm die set (20-40 / 40-80 / 100), mỗi die 1 đợt;
  phế khởi động lại D80-DN100 ~100 kg; sàn MOQ chuyên gia 2.000m nhỏ / 500m 65-100
  → MOQ ống = MAX(hòa vốn, sàn vật lý); ghép đơn = cùng nhóm die + cùng nguyên liệu.
- **ADR-021**: tốc độ chạy theo size (user ghi "kg/h" nhưng kiểm chứng là m/h:
  DN20 350 → DN100 50 m/h; trung bình kg/h suy ra = 140,3 ≈ đúng 140 của mô hình phẳng,
  DN50 = 126 kg/h TP = đúng size neo). DN20-40 tin cậy, ≥DN50 cần xác nhận.
  Giá thành theo giờ máy từng size lệch vs phẳng: DN20 +2,6%, DN100 −4,5%
  (size nhỏ đang trợ giá size lớn). Pha 2: `lineSpeedMPerHour` sửa được trên app.
