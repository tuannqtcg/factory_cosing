### Kiểm chứng (và giới hạn đã gặp)
- Dựng thử bằng Firebase Emulator (firestore+auth, seed `npm run seed:emulator`) + `npm run dev` + Playwright/Chromium để click thử thật.
- **Xác nhận qua REST trực tiếp**: emulator + user `admin@demo.local` + custom claim `role=admin` hoạt động đúng (idToken hợp lệ).
- **Không click-through được trên trình duyệt**: Firebase Auth JS SDK báo `auth/internal-error` NGAY khi gọi `signInWithEmailAndPassword`, TRƯỚC KHI gửi bất kỳ request nào tới emulator (xác nhận bằng cách log toàn bộ network traffic — không có request nào tới port 9100). Đây là giới hạn môi trường sandbox (Chromium headless + Auth SDK, không liên quan tới thay đổi trong ADR-059 — màn hình login không hề bị đụng) — KHÔNG phải lỗi code. Đã dừng lại sau khi cô lập được nguyên nhân, không đào sâu thêm vì tốn thời gian không cần thiết.
- Vì vậy: đã xác nhận bằng typecheck + build + 404 test + đọc code kỹ, nhưng **CHƯA tận mắt thấy panel chạy trên trình duyệt thật**. Phiên sau nếu môi trường dev thật (không phải sandbox) thì nên click-through 1 lần cho chắc.
